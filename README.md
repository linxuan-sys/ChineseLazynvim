# LazyVim 菜单汉化

把 LazyVim 快捷键菜单里的英文变成中文。**就一个文件**，装上就用，删掉就恢复英文。

---

## 效果

按空格（或 `d`、`z`、`a`、`[`、`]` 这些前缀）弹出的菜单，全变中文：

```
原来:  f → +file/find     ff → Find Files (Root Dir)
现在:  f → 文件           ff → 查找文件 (根目录)
```

- 菜单里的**条目数量和原来一样多**，不会多也不会少
- 小图标**不会丢**

---

## 特点

- 只改文字，**快捷键一个都不动**
- 图标保留
- 你的菜单里没有的键，不会硬加进去
- 有些键要等打开文件才出现（比如 git 的 `<leader>gh`），过一会儿也会变中文
- 删掉文件、重启 nvim，就变回英文

---

## 安装

把 `lua/lazyvim-zh.lua` 复制到：

```
~/.config/nvim/lua/plugins/lazyvim-zh.lua
```

然后重启 nvim。不需要改别的东西。

---

## 改成你自己的说法

文件上半部分是"中文对照表"，想改就直接改那里：

```lua
-- 改一条
["<leader>ff"] = "打开文件",

-- 加一个自己写的键
["<leader>t"] = "内置终端",
```

分组的名字（比如 `f → 文件` 里的"文件"）在 `M.xx_g` 那几张表里，例如 `M.cn_g`。

---

## 为什么需要这些代码

- 菜单里的文字来自每条快捷键的说明（`desc`）；图标是 which-key 拿说明里的**英文单词**匹配出来的
- 所以文字一换成中文，图标就会对不上 → 必须先**把图标抓下来**，再换文字
- 有些键要等插件加载、或者打开文件之后才出现 → 所以要**多补几遍**

---

## 不管的部分

- 只有 which-key 的菜单会变中文。选择器标题、Mason、`:checkhealth` 这些不归它管
- 按 `<leader>?` 看到的 LSP 键列表**因人而异**，没有包含
- LazyVim 以后新增的键可能还是英文（大多数会被自动补上，漏的自己加一行）

---

## 卸载

删掉那个文件，重启 nvim，就回到英文。
